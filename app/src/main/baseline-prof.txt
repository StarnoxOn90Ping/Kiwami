# Baseline profile

# Tells Android which code to precompile at install time, so launching the app and opening
# the common screens does not start out slow. Sideloaded installs get it through
# androidx.profileinstaller (already a dependency). Flags: H = hot, S = startup, P = after startup.
# Rarely used areas (downloads, torrents, parsers, addons, widgets, forum, calendar,
# onboarding) are left out on purpose to keep the install small.
